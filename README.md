# Crop Recommendation using Machine Learning

## Project Overview
This project uses machine learning to recommend suitable crops.

## Dataset
- Total records: 2200
- Features: N, P, K, Temperature, Humidity, pH, Rainfall
- Total crop categories: 22

## Tools and Technologies
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Model Performance
- Accuracy: 97.95%

## Purpose
To recommend suitable crops based on soil and environmental conditions.
